## Source changes
1. **internal/db/padkeys.go `padExprRE`.** The old pattern was `^rtrim((?"?…"?)?(::text)?, ' '(::text)?)$`: its unescaped parentheses were regex groups, so it was invalid/inexact. It is now strict and anchored:
   `^rtrim\((?:col|"col")(?:::text)?, ' '::text\)$`
   - Literal parentheses are escaped, and `' '::text` is required (as observed).
   - The column may be quoted, and the cast is optional only to admit TEXT columns (bot user_phone; not yet observed).
   - There are no wildcards. The other catalog predicates (btree, unique, valid/ready/live, non-partial, key count/order, attnum, ci_ai collation, default text opclass) are unchanged.

     It also requires:
